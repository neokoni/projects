# 写作约定

## 侧边栏生成

配置在加载时扫描 `content/<slug>/docs/zh-cn/`，并按下列规则生成侧边栏。

| 位置 | 结果 |
| --- | --- |
| 某一级的 `index.md` | 作为该分组的标题与链接，标题取自文件的一级标题 |
| 子目录 | 作为一个分组，名称取自其 `index.md` 的一级标题，无 `index.md` 时取目录名 |
| 其余 `.md` | 作为分组内的条目，文案取自文件的一级标题 |
| 顶层零散 `.md` | 归入独立分组：该文档区有顶层 `index.md` 时标题为「其他页面」，否则为「概览」 |

一级标题同时作为页面标题与侧边栏文案。修改一级标题即修改菜单文案，无需在第二处同步修改。

## 排序

同级条目默认按文件名排列，`index.md` 固定位于最前。调整顺序在 frontmatter 中设置 `order`：

```md
---
order: 2
---

# 标题
```

`order` 值小者在前，未设置 `order` 的文件排在最后。分组顺序取自各分组 `index.md` 的 `order`。

## 链接

站内跳转使用相对路径，例如 `[写作约定](./writing.md)`。VitePress 将按目录关系计算其 URL。

Markdown 中不得使用 `<http://localhost:5173/...>` 形式的自动链接，构建时的死链检查将判定其无效。地址用行内代码表示。

指向站外的链接使用完整 URL。

## 图片与静态资源

静态资源置于 `public/` 下，以 `/xxx.png` 形式引用。`dist/assets/` 中的哈希文件名不得手工引用。

## 代码块

代码块使用常规围栏语法。需要行内高亮时使用 `js{1,3}` 形式的语法，VitePress 内置支持该语法。
