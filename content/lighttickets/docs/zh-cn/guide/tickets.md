# 议题

议题是这套系统的核心：一次问题反馈、一条建议、一次权限申请，都是议题。议题由模板生成，模板决定要填哪些字段、默认打什么标签、关闭时执行什么动作。

## 提交一个议题

入口是 `/tickets/new`，分两步：

**第一步选模板。** 列表里只有启用中的模板，每个模板一句说明，选它对应的场景即可（比如「Bug 反馈」「权限申请」）。

**第二步填表单。** 表单由模板决定，可能是单行文本、多行文本框、下拉选择、可输入的下拉、复选框、玩家选择，或者一段纯说明文字。带红色 `*` 的是必填项。

填写时注意：

- 标题必填，最长 200 个字符；有些模板会自动在标题前加前缀，不用自己再写一遍；
- 多行文本框支持 Markdown：加粗、列表、表格、代码块都行，顺手贴截图也可以（见 [评论与附件](./comments.md)）；
- 如果模板要求选择「公开 / 隐藏」，二选一才能提交；
- 附件可以直接在编辑区粘贴、拖拽或选择文件，会在提交时一并关联。

提交成功后会自动跳到议题详情页。若模板配了默认受理人与默认标签，会自动指派并挂上标签，被指派的人会收到邮件提醒。

## 找到需要看的议题

议题列表在 `/`，从上到下按提交时间倒序。

顶部搜索框既能直接搜关键字（匹配标题和正文），也能带筛选词组合使用：

| 写法 | 作用 |
| --- | --- |
| `关键字` | 标题或正文包含该词 |
| `status:open` | 只看某个状态，取值 `open`、`in_progress`、`closed`、`invalid`，可用逗号写多个 |
| `type:bug_report` | 只看某个模板 |
| `label:bug` | 只看带某个标签的议题 |
| `from:web` | 只看网页提交的 |
| `from:minecraft` | 只看游戏内提交的 |
| `from:"minecraft:生存服"` | 只看某台服务器提交的，名字带空格要用双引号 |
| `author:Steve` | 只看某个人提交的 |

多个条件用空格隔开，例如 `status:open from:minecraft 卡服`。

## 议题详情页

`/tickets/<编号>` 里能看到：

- 标题与正文，正文按 Markdown 渲染；
- 当前状态，以及下面的操作按钮；
- 受理人（谁在处理）；
- 标签；
- 附加信息：从游戏内提交的议题会带上世界、坐标、游戏模式与来源服务器，方便管理组照着去复现；
- 时间线：评论与变更记录按时间混排，谁在什么时候改了什么一目了然；
- 附件列表。

同一议题的连续编辑会合并成一条变更记录，不会把时间线刷满。

## 状态

议题有四个状态：开放（`open`）、处理中（`in_progress`）、已关闭（`closed`）、无效（`invalid`）。

| 当前状态 | 能变成 |
| --- | --- |
| 开放 | 已关闭 |
| 处理中 | 已关闭 |
| 已关闭 | 开放 |
| 无效 | 开放 |

- 普通用户只能「关闭」或「重新打开」自己提交的议题，不能把状态改成别的，也不能动别人的议题；
- 管理组可以把任意议题改成任意状态，也能把议题标为无效；
- 关闭和标记无效时会记下时间，重新打开会清掉这个时间。

如果两个人几乎同时改同一个议题的状态，后提交的那次会提示状态已被改动，刷新一下再操作即可。

## 公开与隐藏

议题有两种可见性：

- **公开**：谁都能在列表里看到、也能打开；
- **隐藏**：只有发起者本人和管理组能看到。别人既搜不到，直接输地址打开也只会看到「议题不存在」。

模板决定这一项是「固定公开」「固定隐藏」还是「创建时由你选择」。选定之后想改，需要管理组在详情页操作，改动会记进时间线。

从游戏内提交时还会被问一次「是否允许其他玩家看到附加信息」。选择不允许后，普通用户看到的议题里就不显示世界、坐标与来源服务器，只有发起者本人和管理组能看。

## 关闭时的确认

有些模板在议题关闭（或标记为无效）时会要求走一步确认，比如「已为你发放补偿，选择发放内容」。这类议题关闭后，详情页会出现一张待确认卡片：

- 卡片里是要填的字段，带 `*` 的必须填；
- 管理组可以「确认并执行」，也可以选择「不做处理」跳过；
- 提交后模板里配置的动作会在服务器上执行，执行结果显示在这张卡片上；
- 卡片是否对普通用户可见由模板决定，有的是公开结果，有的只有管理组能看见。

如果关闭会触发服务器命令，那么普通用户自己关闭时会被拦下，需要找管理组处理。

## 编辑、指派与标签

| 操作 | 谁能做 | 说明 |
| --- | --- | --- |
| 改标题、正文 | 作者本人或管理组 | 改动会记进时间线 |
| 换受理人 | 管理组 | 候选只有管理组成员；新加的受理人会收到邮件 |
| 加标签、去标签 | 管理组 | 模板自带的标签在创建时就已挂上 |
| 改状态 | 见上一节 | — |
| 切换公开 / 隐藏 | 管理组 | — |
