# 议题

## 议题提交

入口为 `/tickets/new`，提交流程分为两步。

**模板选择。** 列表仅显示启用中的模板，每个模板附一句说明，按场景选择对应模板（如「Bug 反馈」「权限申请」）。

**表单填写。** 字段由模板决定，可为单行文本、多行文本框、下拉选择、可输入的下拉、复选框、玩家选择，或一段纯说明文字。带红色 `*` 的字段为必填项。

填写要求如下：

- 标题为必填项，最长 200 个字符；部分模板将自动在标题前添加前缀，无需重复填写；
- 多行文本框支持 Markdown，加粗、列表、表格与代码块均可使用，截图的粘贴方式见 [评论与附件](./comments.md)；
- 模板要求选择「公开 / 隐藏」时，须选定其中一项方可提交；
- 附件可在编辑区粘贴、拖拽或通过文件选择添加，并在提交时一并关联。

提交成功后将自动跳转至议题详情页。模板配置了默认受理人与默认标签时，将自动指派并添加标签，被指派的用户将收到邮件提醒。

## 议题筛选

议题列表位于 `/`，按提交时间倒序排列。

顶部搜索框支持关键字搜索（匹配标题与正文），也支持筛选词与关键字组合使用：

| 写法 | 作用 |
| --- | --- |
| `关键字` | 标题或正文包含该词 |
| `status:open` | 只看某个状态，取值 `open`、`in_progress`、`closed`、`invalid`，可用逗号写多个 |
| `type:bug_report` | 只看某个模板 |
| `label:bug` | 只看带某个标签的议题 |
| `from:web` | 只看网页提交的 |
| `from:minecraft` | 只看游戏内提交的 |
| `from:"minecraft:生存服"` | 只看某台服务器提交的，名字带空格要用双引号 |
| `author:Steve` | 只看某个人提交的 |

多个条件以空格分隔，例如 `status:open from:minecraft 卡服`。

## 议题详情页

`/tickets/<编号>` 包含以下内容：

- 标题与正文，正文按 Markdown 渲染；
- 当前状态及其下方的操作按钮；
- 受理人，即当前处理人；
- 标签；
- 附加信息：从游戏内提交的议题附带世界、坐标、游戏模式与来源服务器，供管理组复现；
- 时间线：评论与变更记录按时间混排，含操作者、操作时间与变更内容；
- 附件列表。

同一议题的连续编辑将合并为一条变更记录。

## 状态与流转

议题有四个状态：开放（`open`）、处理中（`in_progress`）、已关闭（`closed`）、无效（`invalid`）。

| 当前状态 | 可变更为 |
| --- | --- |
| 开放 | 已关闭 |
| 处理中 | 已关闭 |
| 已关闭 | 开放 |
| 无效 | 开放 |

- 普通用户仅可「关闭」或「重新打开」本人提交的议题，无法将状态改为其他取值，也无法操作他人议题；
- 管理组可将任意议题改为任意状态，并可将议题标记为无效；
- 关闭与标记无效时将记录时间，重新打开将清除该时间。

两个用户几乎同时变更同一议题的状态时，后提交的一次将提示状态已被改动，需刷新页面后重新操作。

## 可见性

议题有两种可见性：

- **公开**：所有用户均可在列表中看到并打开；
- **隐藏**：仅发起者本人与管理组可见。其他用户无法搜索到该议题，直接访问地址时仅显示「议题不存在」。

可见性由模板决定，取值为「固定公开」「固定隐藏」或「创建时由发起者选择」。选定后如需变更，须由管理组在详情页操作，变更将记录至时间线。

从游戏内提交时，将额外询问「是否允许其他玩家看到附加信息」。选择不允许后，普通用户查看该议题时，页面不显示世界、坐标与来源服务器，仅发起者本人与管理组可见。

## 关闭确认

部分模板在议题关闭（或标记为无效）时要求完成一步确认，确认内容由模板定义，如补偿发放内容的选择。此类议题关闭后，详情页将出现一张待确认卡片：

- 卡片内为待填写的字段，带 `*` 的字段须填写；
- 管理组可「确认并执行」，也可选择「不做处理」跳过；
- 提交后，模板中配置的动作将在服务器上执行，执行结果显示在该卡片上；
- 卡片是否对普通用户可见由模板决定：部分模板公开结果，部分仅管理组可见。

关闭操作会触发服务器命令时，普通用户自行关闭将被阻止，须由管理组处理。

## 编辑、指派与标签

| 操作 | 可执行者 | 说明 |
| --- | --- | --- |
| 改标题、正文 | 作者本人或管理组 | 改动会记进时间线 |
| 换受理人 | 管理组 | 候选只有管理组成员；新加的受理人会收到邮件 |
| 加标签、去标签 | 管理组 | 模板自带的标签在创建时就已挂上 |
| 改状态 | 见上一节 | — |
| 切换公开 / 隐藏 | 管理组 | — |
