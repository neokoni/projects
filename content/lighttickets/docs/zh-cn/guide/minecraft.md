# 游戏内使用

装了 LightTickets 插件后，玩家可以不下线处理议题：查列表、看详情、提交、评论、看通知都在聊天栏里完成。所有命令以 `/lit` 开头，`/lighttickets` 是同一个命令的别名。

## 先把账号绑上

游戏内操作要求先有站点账户，两种方式任选其一。

### 已有账户：用绑定码

1. 游戏内执行 `/lit bind`，聊天栏给出一个 6 位绑定码；
2. 打开站点「个人资料 → Minecraft 绑定」，把绑定码填进去；
3. 绑定成功后回到游戏，`/lit account` 能看到自己的账户信息就说明通了。

绑定码 5 分钟内有效，重新执行 `/lit bind` 会作废旧码。绑定完成后请保管好这份关联——插件靠它证明「这个游戏账号就是那个站点账户」，换了就不需要重新绑，但要是在网页解绑过，就得重新走一次。

### 新玩家：用注册链接

执行 `/lit register`，聊天栏会给出一个网页注册链接。打开后按普通注册填完，游戏账号会自动绑上，不用再执行 `/lit bind`。

这条命令需要管理员打开「允许 Minecraft 注册」，并且后台填好站点地址，否则拿不到链接。

## 命令一览

| 命令 | 作用 |
| --- | --- |
| `/lit bind` | 生成 6 位绑定码，用于绑定已有账户 |
| `/lit register` | 生成一次性注册链接，网页注册后自动绑定 |
| `/lit account` | 查看当前绑定的账户信息，附解绑按钮 |
| `/lit unbind` | 只提示去网页解绑——解绑必须在网页端完成 |
| `/lit ticket create` | 弹出模板列表，点一个开始提交 |
| `/lit ticket create <模板>` | 直接用指定模板开始提交 |
| `/lit ticket list` | 看第 1 页议题 |
| `/lit ticket list <页码>` | 看指定页 |
| `/lit ticket list:open` | 按状态筛选，`open`、`in_progress`、`closed`、`invalid` 都可替换到冒号后面 |
| `/lit ticket search <关键词>` | 搜索议题 |
| `/lit ticket search --page <页码> <关键词>` | 带页码搜索，两个参数的顺序是固定的 |
| `/lit ticket info <编号>` | 看议题详情 |
| `/lit ticket info <编号> <评论页码>` | 看详情并翻到指定的评论页 |
| `/lit ticket comment <编号>` | 给议题发评论 |
| `/lit ticket comment <编号> reply <序号>` | 引用第几条评论后回复，序号从 `0` 开始 |
| `/lit ticket status <编号>` | 弹出状态列表，点一下即切换 |
| `/lit ticket status <编号> <状态>` | 直接切到指定状态 |
| `/lit reload` | 管理员用：重载插件配置 |
| `/lit status` | 管理员用：查看插件与平台的连接状态 |

哪些人能执行哪条命令由服务器管理员在权限里配置；如果执行后提示没有权限，找服主分配即可，配置方法见 [插件部署](../deploy/plugin.md)。

## 提交与评论的输入方式

`/lit ticket create` 和 `/lit ticket comment` 都会进入「用下一条聊天消息当输入」的状态：

- 命令发出去后，聊天栏会提示你输入内容，屏幕上也会显示当前在填哪一项；
- 输入内容不支持一次写很多行，按提示逐项填就行；想写长文建议到网页上提交；
- 中途想放弃，直接输入 `cancel` 取消；
- 模板选择、状态选择这类需要挑一项的步骤，直接点聊天栏里的可点击选项。

从游戏内提交时会额外问一次「是否允许其他玩家查看附加信息」，回答后议题会带上世界、坐标与游戏模式，方便管理组照着复现。

## 搜索写法

`/lit ticket search` 后面可以跟普通关键词，也可以带筛选词，规则和网页搜索框一样：

| 写法 | 作用 |
| --- | --- |
| `卡服` | 标题或正文包含这个词 |
| `author:Steve` | 某个玩家提交的 |
| `type:bug_report` | 某个模板提交的 |
| `status:open` | 某个状态 |
| `from:web` / `from:minecraft` | 网页提交的 / 游戏内提交的 |
| `from:"minecraft:生存服"` | 某台服务器提交的 |

筛选值里有空格时用双引号括起来，引号内的 `\"` 表示一个引号、`\\` 表示一个反斜杠。多个条件用空格隔开，也能和普通关键词混着写。

## 游戏内提醒

绑定账号并在线时，下面两种情况会在聊天栏收到一条提醒：

- 你的议题有新评论；
- 你的议题状态发生变化。

提醒整行可点，点了等于执行 `/lit ticket info <编号>`。收到提醒后本地缓存会随之刷新，接着 `/lit ticket list` 就能看到最新内容。

## 常见提示

| 提示 | 原因与处理 |
| --- | --- |
| 还没有绑定账号，请先执行 `/lit bind` | 当前游戏账号没有关联站点账户，注册或绑定后再试 |
| 绑定凭据无效，请先在网页解绑后重新绑定 | 网页端已经解绑或凭据失效，重新走一次绑定 |
| 平台要求登录后才能查看议题 | 站点开启了「要求登录查看议题」，先绑定账号 |
| 没有权限 | 服务器没给这个命令对应的权限，找服主分配 |
| 操作太频繁 | 触发了频率限制，等一会儿再试 |

如果 `/lit status` 显示连不上平台，先确认服务器能访问站点地址，再检查插件配置里的站点地址与密钥是否正确。
