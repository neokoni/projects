# 游戏内使用

## 账号绑定

游戏内操作以站点账户为前提，绑定方式有以下两种。

### 已有账户：使用绑定码

1. 在游戏内执行 `/lit bind`，聊天栏将给出一个 6 位绑定码；
2. 打开站点「个人资料 → Minecraft 绑定」，填入该绑定码；
3. 绑定成功后返回游戏，`/lit account` 显示账户信息即表示绑定完成。

绑定码 5 分钟内有效，重新执行 `/lit bind` 将作废旧码。绑定完成后妥善保管该关联：插件以该关联证明游戏账号与站点账户的对应关系。若已在网页端解绑，则须重新绑定。

### 新玩家：使用注册链接

执行 `/lit register`，聊天栏将给出一个网页注册链接。打开链接并按普通流程完成注册后，游戏账号将自动绑定，无需再执行 `/lit bind`。

该命令要求管理员开启「允许 Minecraft 注册」并在后台填写站点地址，否则无法获取链接。

## 命令一览

| 命令 | 说明 |
| --- | --- |
| `/lit bind` | 生成 6 位绑定码，用于已有账户的绑定 |
| `/lit register` | 生成一次性注册链接，网页注册后自动完成绑定 |
| `/lit account` | 查看当前绑定的账户信息，附解绑按钮 |
| `/lit unbind` | 仅提示前往网页端解绑；解绑须在网页端完成 |
| `/lit ticket create` | 弹出模板列表，选择其一后开始提交 |
| `/lit ticket create <模板>` | 以指定模板直接开始提交 |
| `/lit ticket list` | 查看第 1 页议题 |
| `/lit ticket list <页码>` | 查看指定页议题 |
| `/lit ticket list:open` | 按状态筛选，`open`、`in_progress`、`closed`、`invalid` 均可替换至冒号后 |
| `/lit ticket search <关键词>` | 搜索议题 |
| `/lit ticket search --page <页码> <关键词>` | 带页码搜索，两个参数的顺序固定 |
| `/lit ticket info <编号>` | 查看议题详情 |
| `/lit ticket info <编号> <评论页码>` | 查看详情并翻至指定的评论页 |
| `/lit ticket comment <编号>` | 为议题发表评论 |
| `/lit ticket comment <编号> reply <序号>` | 引用指定评论后回复，序号从 `0` 开始 |
| `/lit ticket status <编号>` | 弹出状态列表，选择后即切换 |
| `/lit ticket status <编号> <状态>` | 直接切换至指定状态 |
| `/lit reload` | 管理员用：重载插件配置 |
| `/lit status` | 管理员用：查看插件与平台的连接状态 |

各命令的执行权限由服务器管理员配置；执行后若提示无权限，联系服主分配，配置方法见 [插件部署](../deploy/plugin.md)。

## 提交与评论的输入方式

`/lit ticket create` 与 `/lit ticket comment` 均进入「以下一条聊天消息作为输入」的状态：

- 命令发出后，聊天栏将提示输入内容，屏幕同时显示当前填写项；
- 输入内容不支持一次写入多行，须按提示逐项填写；篇幅较长时建议在网页端提交；
- 如需放弃，直接输入 `cancel` 取消；
- 模板选择、状态选择等需要选定一项的步骤，直接点击聊天栏中的可点击选项。

从游戏内提交时将额外询问一次「是否允许其他玩家查看附加信息」，回答后议题将附带世界、坐标与游戏模式，供管理组复现。

## 搜索写法

`/lit ticket search` 后可跟普通关键词或筛选词，规则与网页搜索框一致：

| 写法 | 说明 |
| --- | --- |
| `卡服` | 标题或正文包含该词 |
| `author:Steve` | 由指定玩家提交 |
| `type:bug_report` | 由指定模板提交 |
| `status:open` | 指定状态 |
| `from:web` / `from:minecraft` | 网页端提交 / 游戏内提交 |
| `from:"minecraft:生存服"` | 由指定服务器提交 |

筛选值含空格时须用双引号括起，引号内的 `\"` 表示一个引号，`\\` 表示一个反斜杠。多个条件以空格分隔，也可与普通关键词混用。

## 游戏内提醒

绑定账号并处于在线状态时，以下两种情况将在聊天栏收到提醒：

- 议题有新评论；
- 议题状态发生变化。

提醒整行可点击，点击等同执行 `/lit ticket info <编号>`。收到提醒后本地缓存随之刷新，此后执行 `/lit ticket list` 即可看到最新内容。

## 提示与处理

| 提示 | 原因与处理 |
| --- | --- |
| 还没有绑定账号，请先执行 `/lit bind` | 当前游戏账号未关联站点账户，须先注册或绑定后重试 |
| 绑定凭据无效，请先在网页解绑后重新绑定 | 网页端已解绑或凭据失效，须重新执行一次绑定 |
| 平台要求登录后才能查看议题 | 站点已开启「要求登录查看议题」，须先绑定账号 |
| 没有权限 | 服务器未授予该命令对应的权限，联系服主分配 |
| 操作太频繁 | 已触发频率限制，稍后重试 |

若 `/lit status` 显示无法连接平台，先确认服务器可访问站点地址，再检查插件配置中的站点地址与密钥是否正确。
