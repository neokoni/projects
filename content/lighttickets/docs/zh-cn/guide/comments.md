# 评论与附件

## 发表评论

在议题详情页底部有评论框，写好点「发表评论」即可。评论框同样支持 Markdown，也能直接粘贴或拖拽图片。

评论框旁边还有几个一次到位的按钮：

- 「评论并关闭」：发表评论的同时关闭议题；
- 「评论并关闭（标记无效）」：发表评论并把议题标为无效（只对管理组显示）；
- 「评论并重新打开」：发表评论并重新打开议题。

在游戏里提交的评论，时间线上会带一个 `MC` 标记，方便区分来源。

## 支持哪些格式

正文和评论用同一套渲染规则：

| 写法 | 效果 |
| --- | --- |
| 标题、段落、加粗、斜体、删除线 | 支持 |
| 有序、无序列表 | 支持 |
| 任务列表（`- [x]`） | 显示为勾选框，但只是展示，点不动 |
| 表格 | 支持 |
| 代码块与行内代码 | 支持，代码块右上角有复制按钮（不做语法高亮） |
| 图片 | 支持，直接粘贴上传或用图片链接 |
| 链接 | 支持，裸链接会自动识别，一律在新标签页打开 |
| HTML 标签 | 不支持，会当成普通文字显示 |

换行按你输入的行数原样保留，写几行就显示几行。

## 引用回复

评论上的「引用回复」会把被回复的内容以引用块插进编辑框，你在下面接着写就行。

游戏内的写法是 `/lit ticket comment <编号> reply <序号>`，序号从 `0` 开始数，也就是列表里的第一条是 `0`。

## 编辑与删除

| 操作 | 谁能做 |
| --- | --- |
| 编辑评论内容 | 只有评论作者本人 |
| 删除评论 | 评论作者本人，或管理组 |

管理组可以删别人的评论，但不能改别人的评论。编辑过的评论会在时间线上显示为「编辑了评论」，可以展开看修改前后。删除评论时，挂在这条评论下的附件会一并清理。

## 会收到什么通知

评论、状态变更、被指派都会提醒，分两种渠道。

### 邮件

同时满足这几条才会发信：站点开启了议题邮件通知、站点配好了发信服务、收件人打开了「接收议题邮件通知」，而且操作者不是收件人本人。

- 有新评论：发给议题作者；
- 状态变了：发给议题作者，信里写明从什么状态变成什么状态；
- 被指派：发给新加的受理人。

每封邮件底部都有退订链接（对应 `/unsubscribe`），点一次就会关掉这个账户的全部议题邮件提醒。

发信失败不会影响评论和状态本身，也不会补发。

### 游戏内

绑定了 Minecraft 且在线的话，聊天栏会收到提醒：

- 有新评论：显示议题标题、评论人和一小段内容；
- 状态变了：显示议题标题、变更前后的状态和操作人。

同一条议题，只有作者和被指派的人会收到；自己操作触发的通知不会再发给自己。整行提醒可以点，点了等于执行 `/lit ticket info <编号>`，进详情看。

## 附件

### 能传什么

| 格式 | 页面里怎么显示 |
| --- | --- |
| PNG、JPEG、GIF、WebP | 直接显示图片 |
| PDF、纯文本 | 显示为下载链接 |

单个文件最大 10 MiB。上传时会检查文件内容与格式是否对得上，扩展名改了但内容不对会被拒绝。

### 一个账户能攒多少

先传后用的文件会先占一个临时位置：

- 每个账户最多攒 50 MiB 未使用的附件，满了要先提交议题或评论，或者把没用的删掉；
- 这些临时附件 7 天后会自动过期，过期后既不能用也无法下载；
- 站点会定期清理过期的临时文件。

### 谁能看、谁能删

挂在议题或评论上的附件，跟着议题的可见性走：能看见议题就能下载附件。

删除只能由上传者本人或管理员操作，管理组（非管理员）不能删别人上传的附件。

附件实际存在哪里（服务器本地目录或对象存储）由管理员在后台「存储」页决定，切换后新上传的文件走新位置，旧文件仍然能正常打开。
