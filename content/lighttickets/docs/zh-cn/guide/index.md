# 使用指南

## 三种身份

| | 访客（未登录） | 登录用户 | 管理组 |
| --- | --- | --- | --- |
| 浏览议题 | 只有公开议题 | 公开议题 + 自己提交的隐藏议题 | 全部议题（含隐藏） |
| 创建议题 | 不能 | 可以 | 可以 |
| 发表评论 | 不能 | 可以 | 可以 |
| 编辑自己的内容 | 不能 | 自行编辑 | 自行编辑 |
| 改状态 / 指派 / 打标签 | 不能 | 只能关闭或重开自己的议题 | 全部议题 |
| 确认完成钩子 | 不能 | 不能 | 可以 |
| 删除他人评论 | 不能 | 不能 | 可以 |
| 站点设置与管理模块 | 不能 | 不能 | 仅管理员 |

后台里的身份分别显示为 `player`（普通用户）、`staff`（管理组）、`admin`（管理员），管理员拥有一切权限。

## 页面入口

| 地址 | 用途 | 是否需要登录 |
| --- | --- | --- |
| `/` | 议题列表与搜索 | 否 |
| `/tickets/new` | 创建议题 | 是 |
| `/tickets/<编号>` | 议题详情 | 否 |
| `/profile` | 个人资料（Minecraft 绑定、语言、通知） | 是 |
| `/login` / `/register` | 登录 / 注册 | 否 |
| `/forgot-password` / `/reset-password` | 申请重置密码 / 用邮件链接设置新密码 | 否 |
| `/unsubscribe` | 从邮件里退订通知 | 否 |
| `/cancel-email-change` | 从邮件里撤销换邮箱 | 否 |
| `/admin` | 管理后台（非管理员会被送回议题列表） | 管理员 |

管理后台默认打开「标签」页，左侧固定 12 项：标签、服务器、模板、玩家组、用户、设置、邮件、Turnstile、限流策略、外部登录、存储、关于。

## 不登录能看到什么

默认情况下不登录也能浏览议题列表和任何公开议题，但不能发言、不能提交、也看不到隐藏议题。

如果管理员在「设置」里打开了「要求登录查看议题」，那么除登录、注册、重置密码这些入口页外，其余页面都要先登录；游戏内也会提示先绑定账号（`/lit bind`）。

无论这一项怎么设置，创建议题、发表评论、上传附件、进入后台都必须登录。

## 界面语言

网页界面语言可以在「个人资料 → 语言」里切换，选择会被记住。没选过时，界面跟随站点默认语言，站点默认语言由管理员在后台设置。

邮件（注册验证码、重置密码、换邮箱、议题通知）不受个人选择影响，始终使用站点默认语言。
