# 使用指南

本组文档面向两类读者：在网页或游戏里提交、跟进议题的玩家，以及维护站点与插件的管理员。页面默认站点已经完成初始化（首次启动会进入 `/setup` 引导页）并至少配置了一台服务器与一个模板。

## 角色与能力

系统只有三种角色：`player`、`staff`、`admin`。`staff` 与 `admin` 合称管理组（前端 `isStaff`），`admin` 继承管理组的全部能力并额外拥有全部后台权限。

| 能力 | player | staff | admin |
| --- | --- | --- | --- |
| 浏览议题列表与详情 | 是（受可见性限制） | 是 | 是 |
| 创建议题 | 是（归属于自己） | 是 | 是 |
| 发表评论 | 是 | 是 | 是 |
| 编辑自己议题的标题与正文 | 是 | 是 | 是 |
| 编辑自己的评论 | 是 | 是 | 是 |
| 关闭 / 重新打开自己的议题 | 是（仅 open ↔ closed） | 是 | 是 |
| 将议题状态改为任意合法目标 | 否 | 是 | 是 |
| 将议题标记为 invalid | 否 | 是 | 是 |
| 更改议题可见性（hidden） | 否 | 是 | 是 |
| 指派 / 解除受理人 | 否 | 是 | 是 |
| 添加 / 移除议题标签 | 否 | 是 | 是 |
| 提交或跳过完成钩子决策 | 否 | 是 | 是 |
| 删除他人评论 | 否 | 是 | 是 |
| 编辑他人评论 | 否 | 否 | 否 |
| 查看隐藏议题 | 仅自己创建的 | 是 | 是 |
| 查看被创建者限制的议题上下文 | 否（作者本人除外） | 是 | 是 |
| 标签、模板、玩家组、服务器与 API Key 管理 | 否 | 否 | 是 |
| 用户角色调整、删除用户 | 否 | 否 | 是 |
| 站点设置、邮件、Turnstile、限流、外部登录、存储 | 否 | 否 | 是 |

几条容易踩的边界：

- 玩家只能把议题改成 `open` 或 `closed`，并且只能操作自己的议题；`invalid` 只能由管理组产生，也只能由管理组重新打开。
- 评论的「编辑」只属于作者本人，管理组只能删除；删除评论会先清理该评论的全部附件。
- 「指派受理人」的候选范围固定为 staff 与 admin，玩家不会出现在候选列表里。

## 站点主要页面

| 路径 | 页面 | 路由权限 |
| --- | --- | --- |
| `/` | 议题列表与搜索 | `public` |
| `/tickets/new` | 创建议题（模板选择 + 动态表单） | `auth` |
| `/tickets/:id` | 议题详情 | `public` |
| `/profile` | 个人资料 | `auth` |
| `/login` | 登录 | `guest` |
| `/register` | 注册 | `guest` |
| `/forgot-password` | 申请密码重置 | `guest` |
| `/reset-password` | 使用重置链接设置新密码 | `guest`（允许已登录访问） |
| `/unsubscribe` | 邮件通知退订 | `guest`（允许已登录访问） |
| `/cancel-email-change` | 撤销邮箱更换 | `guest`（允许已登录访问） |
| `/federatedauth/register` | 外部登录补充注册信息 | `guest` |
| `/federatedauth/complete` | 外部登录完成跳转 | `public` |
| `/setup` | 初始化向导 | `setup` |
| `/connection-error` | 后端不可达提示 | `public` |

管理后台以 `/admin` 为根，默认重定向到 `/admin/labels`，子页面包括：`labels`、`servers`、`templates`、`player-groups`、`users`、`settings`、`mail`、`turnstile`、`rate-limit`、`federatedauth`、`storage`、`about`。非 admin 用户访问后台会被重定向回议题列表。

## 登录要求与匿名可见内容

站点设置里的 `requireLogin` 决定「不登录能看到多少内容」：

- 关闭时（默认）：`/`、`/tickets/:id` 以及它们依赖的议题、评论、审计、附件下载接口对匿名开放，但只返回 `hidden = false` 的议题；匿名用户不能创建议题、不能评论、不能上传附件。
- 开启时：除 `guest` 与 `setup` 页面外全部要求登录，未登录会被带到 `/login?redirect=<原路径>`；对应的后端接口返回 401；游戏内也会提示需要先绑定（`/lit bind`）。

无论开关如何，以下内容始终需要登录：创建议题、个人资料、管理后台、评论发表、附件上传。

## 语言

语言有三层来源，回退顺序固定为：

1. 当前浏览器的语言偏好 cookie `lt_language`（有效期一年，`Path=/`）；
2. 站点设置里的默认语言（平台默认值，来自管理后台「设置」页）；
3. 内置兜底 `zh-CN`。

平台内置 `zh-CN` 与 `en-US` 语言包，也可以把自定义语言文件放进数据目录的 `locales/` 下覆盖或扩展（同名语言以自定义文件为准，缺失的键回退到内置文案）。个人语言偏好只影响网页界面，注册验证码、密码重置、邮箱更换与议题通知等邮件一律使用平台默认语言。
