# 使用指南

## 身份与权限

| 权限项 | 访客（未登录） | 登录用户 | 管理组 |
| --- | --- | --- | --- |
| 浏览议题 | 仅公开议题 | 公开议题与本人提交的隐藏议题 | 全部议题（含隐藏） |
| 创建议题 | 不可 | 可 | 可 |
| 发表评论 | 不可 | 可 | 可 |
| 编辑本人内容 | 不可 | 可自行编辑 | 可自行编辑 |
| 改状态、指派、打标签 | 不可 | 仅可关闭或重开本人议题 | 全部议题 |
| 确认完成钩子 | 不可 | 不可 | 可 |
| 删除他人评论 | 不可 | 不可 | 可 |
| 站点设置与管理模块 | 不可 | 不可 | 仅限管理员 |

管理后台中，身份显示为 `player`（普通用户）、`staff`（管理组）、`admin`（管理员）。管理员具备全部权限。

## 页面入口

| 地址 | 用途 | 登录要求 |
| --- | --- | --- |
| `/` | 议题列表与搜索 | 否 |
| `/tickets/new` | 创建议题 | 是 |
| `/tickets/<编号>` | 议题详情 | 否 |
| `/profile` | 个人资料（Minecraft 绑定、语言、通知） | 是 |
| `/login` / `/register` | 登录 / 注册 | 否 |
| `/forgot-password` / `/reset-password` | 申请重置密码 / 通过邮件链接设置新密码 | 否 |
| `/unsubscribe` | 通过邮件退订通知 | 否 |
| `/cancel-email-change` | 通过邮件撤销邮箱变更 | 否 |
| `/admin` | 管理后台（非管理员将被送回议题列表） | 管理员 |

管理后台默认进入「标签」页，左侧导航固定为 12 项：标签、服务器、模板、玩家组、用户、设置、邮件、Turnstile、限流策略、外部登录、存储、关于。

## 未登录的可见范围

默认设置下，未登录状态可浏览议题列表与全部公开议题，不可发表评论，不可提交议题，亦不可查看隐藏议题。

管理员在「设置」中启用「要求登录查看议题」后，除登录、注册、重置密码等入口页外，其余页面均须先登录；游戏内将提示先绑定账号（`/lit bind`）。

无论该项设置如何，创建议题、发表评论、上传附件与进入管理后台均须登录。

## 界面语言

网页界面语言在「个人资料 → 语言」中切换，所选项将被保存。未作选择时，界面跟随站点默认语言；站点默认语言由管理员在管理后台设置。

邮件（注册验证码、重置密码、换邮箱、议题通知）不受个人选择影响，始终使用站点默认语言。
