# 管理后台

后台在 `/admin`，只有管理员能进；其他人打开会被送回议题列表。左侧固定 12 项：标签、服务器、模板、玩家组、用户、设置、邮件、Turnstile、限流策略、外部登录、存储、关于。

管理组的日常处理（改状态、指派、打标签）都在议题详情页完成，不需要进后台。

## 设置

这一页决定站点对外呈现的样子和开放程度。

| 项目 | 作用 | 注意 |
| --- | --- | --- |
| 站点名称 | 页面标题、邮件抬头、页脚里显示的站点名 | 留空会用内置名称 |
| 站点地址 | 生成邮件链接、游戏内注册链接、外部登录回跳的基准地址 | 必须是带协议、不带路径的完整域名（如 `https://tickets.example.com`）。填错会让邮件里的链接和注册链接全部指向错误地址 |
| 默认语言 | 平台默认语言，也是所有通知邮件的语言 | 改动影响之后的全部邮件 |
| 页脚内容 | 支持 Markdown，可放备案号、版权声明 | 全站公开可见 |
| 站点图标 / Logo | 分浅色与暗色两套，支持 PNG、JPEG、WebP、GIF、SVG，单个文件最大 2 MiB | 暗色模式下优先用暗色版；没上传就退回浅色版，再退回内置图标 |
| 要求登录查看议题 | 开启后未登录不能看议题 | 游戏内匿名查议题也会被拒，玩家必须先绑定 |
| 允许网页注册 | 关闭后登录页不显示注册入口 | 外部登录也不能再建新账户 |
| 允许 Minecraft 注册 | 关闭后游戏内 `/lit register` 拿不到链接 | 已有账户的玩家仍可用 `/lit bind` |
| 发送议题邮件通知 | 评论、状态变更、指派是否发邮件 | 需要先在「邮件」页配好发信服务 |

站点地址还决定「忘记密码」和「换邮箱」能不能用：只有 HTTPS 的站点地址才能发这两类邮件，否则入口直接报错。

## 模板

模板决定创建议题时要填什么、默认打什么标签、关闭时执行什么动作。编辑页分四段：

- **基础信息**：模板标识（建好后不能改）、显示名称、描述、标题前缀、默认可见性、是否启用、默认受理人、默认标签。
- **表单字段**：单行文本、多行文本、说明文字、下拉、可输入的下拉、复选框、玩家选择，可拖动排序，可设必填。
- **完成钩子**：为「议题关闭」和「议题标记无效」两种时机配置动作，可以是服务器命令、带颜色的提示文字，也可以要求管理员做一次人工确认。
- **编辑原文**：直接改模板配置文件，与上面的图形编辑实时同步。

默认可见性三选一：

| 选项 | 效果 |
| --- | --- |
| 始终公开 | 新议题所有人可见，创建者不能改 |
| 始终隐藏 | 新议题只有发起者与管理组可见 |
| 由创建者选择 | 创建时必须二选一，不选不能提交 |

首次初始化时，平台会放出几份现成模板（Bug 反馈、举报、建议、权限申请、完整示例）到数据目录，之后它们和自己新建的模板完全平级，可以随便改。停用某个模板后它不再出现在创建页，历史议题不受影响；删除模板同样不影响已经提交的议题。

字段怎么写、钩子怎么配见 [议题模板](../template/index.md)。

## 标签

每个标签有一个标识（只能字母、数字、下划线、短横线，建好后不能改）、显示名称、颜色和说明。标签用于列表筛选，模板也可以引用标签实现自动打标。

## 玩家组

玩家组是模板里「玩家选择」字段的候选名单。

- 可以在页面里手动加成员（空格或逗号分隔多个名字）、改名、移除；
- 插件也能自动写入：在插件配置里打开玩家组上传并填好组名，玩家进服时会自动进组；
- 删掉某个组之前，先确认没有模板或完成钩子在用它，否则相关表单会失效。

## 用户

用户列表按注册时间倒序。管理员可以：

- **调整身份**：普通用户 / 管理组 / 管理员。改动后对方需要重新登录才能生效；
- **删除用户**：这是软删除，账户的邮箱、密码、头像与游戏绑定会被清空，历史议题与评论保留，作者位置显示为已删除账户；
- 不能删除自己。

## 服务器与 API Key

服务器代表议题来源，也是插件接入的身份。每台服务器有：

- **服务器 ID**：平台内唯一；
- **识别 ID**：用来对上 Velocity 插件上报的服务器名，留空就等同服务器 ID；
- 别称、地址、描述，只用于展示和筛选。

API Key 单独管理，两种类型：

| 类型 | 绑定范围 | 适用 |
| --- | --- | --- |
| Paper / Folia | 必须且只能绑一台服务器 | 单机直连 |
| Velocity | 可授权多台服务器 | 代理端后面挂多台后端服 |

操作上的注意：

- 新建 Key 时明文只显示一次，当场复制到插件配置里，之后看不到；
- 「重新生成」会让旧 Key 立刻失效，所有用它的服务器会连不上，必须同步改插件配置；
- 修改 Key 授权的服务器列表会立即改变它能访问的范围；
- 服务器还被 Key 绑着时不能删除，要先把 Key 处理掉；
- 两台服务器不能用同一个识别 ID。

## 存储

存储页管附件放在哪里，以及临时附件的额度。

- **本地目录**：文件存在服务器磁盘上，适合单机部署；
- **对象存储（S3 兼容）**：填服务地址、区域、桶名、访问凭据，兼容 MinIO 这类需要 path-style 的服务，可设置下载链接有效期。

「测试连接」测的是**已经保存**的配置，不是表单里还没保存的内容，所以先保存再测试；用本地目录时这项会直接提示还没配置对象存储。

切换存储后，新上传的文件走新位置，旧文件仍按各自原来的位置读取——但改动本地目录或桶的配置本身会影响该位置上的所有附件，动手前先备份。

临时附件额度：

- 单个账户未使用的附件总上限，默认 50 MiB；
- 是否让未使用的附件自动过期，默认开启；
- 过期天数，默认 7 天。

## 邮件

填发信服务器的主机、端口、加密方式（465 一般用 SSL，587 一般用 TLS）、账号、密码、发件名称与发件邮箱，并有「测试连接」按钮。

打开邮件服务后三件事会跟着可用：网页注册要求邮箱验证码、忘记密码可以发信、换邮箱可以发信。关闭后这些功能一起停用，密码超过忘记的用户只能找管理员重置。

## Turnstile

配置 Cloudflare Turnstile 的两把 Key（站点 Key 与密钥），用于注册、登录、忘记密码和外部登录注册时的人机验证。启用时两个 Key 都要填；密钥编辑框留空表示保持原值。

## 限流策略

| 规则 | 默认 | 说明 |
| --- | --- | --- |
| 全局请求 | 60 秒内 100 次 | 按访问 IP 统计 |
| 登录注册类 | 60 秒内 10 次 | 登录、注册、刷新登录状态、外部登录 |
| 邮件发送冷却 | 60 秒 | 注册验证码与忘记密码共用 |
| 游戏绑定保护 | 连错 5 次锁 15 分钟 | 绑定码输错的保护 |

超限时页面会提示稍后再试。改动立即生效。

## 外部登录

配置通用的 OIDC / OAuth 2.0 登录方式：显示名称、图标、协议、服务地址、授权与用户信息端点、回调地址、客户端 ID 与密钥、权限范围、字段映射、是否启用、是否允许创建账户。

- 选 OIDC 时必须填服务地址且权限范围包含 `openid`；选 OAuth 2.0 时三个端点都要填；
- 密钥是加密保存的，编辑时留空表示沿用旧值；
- 页面有「测试」可以检查配置是否可用；
- 删除这种登录方式前必须先解除所有绑定，也可以「一键解绑全部」——账户与数据都保留；
- 关闭「允许创建账户」后，没用过的人就无法通过它注册，只能登录后在个人资料里绑定。

## 关于

显示平台名称、构建版本、提交号与仓库地址。反馈问题时把这几项一起附上最省事。

## 变更记录在哪看

审计记录直接展示在议题详情页的时间线里，能看见该议题的人都能看到：状态变更、标题正文修改、可见性变化、标签增删、受理人变化、评论编辑，以及完成钩子的处理动作。连续的小改动会合并成一条。

完成钩子的执行结果也显示在议题详情页，只有管理组能看见。投递失败的动作会留在投递记录里等待重试，目前后台还没有单独的页面入口。
