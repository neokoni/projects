# 管理后台

## 设置

设置页控制站点的对外呈现与开放程度。

| 字段 | 作用 | 说明 |
| --- | --- | --- |
| 站点名称 | 页面标题、邮件抬头、页脚中显示的站点名 | 留空时使用内置名称 |
| 站点地址 | 生成邮件链接、游戏内注册链接、外部登录回跳的基准地址 | 须为带协议、不带路径的完整域名（如 `https://tickets.example.com`）。填错将使邮件中的链接与注册链接指向错误地址 |
| 默认语言 | 平台默认语言，同时为所有通知邮件的语言 | 改动影响此后的全部邮件；新增语言与文案修改见 [多语言](../i18n/index.md) |
| 页脚内容 | 支持 Markdown，可放置备案号、版权声明 | 全站公开可见 |
| 站点图标 / Logo | 分浅色与暗色两套，支持 PNG、JPEG、WebP、GIF、SVG，单个文件最大 2 MiB | 暗色模式下优先使用暗色版；未上传时回退到浅色版，再回退到内置图标 |
| 要求登录查看议题 | 开启后未登录用户不能查看议题 | 游戏内匿名查看议题亦将被拒绝，玩家须先绑定 |
| 允许网页注册 | 关闭后登录页不显示注册入口 | 外部登录亦不能创建新账户 |
| 允许 Minecraft 注册 | 关闭后游戏内 `/lit register` 无法获取链接 | 已有账户的玩家仍可使用 `/lit bind` |
| 发送议题邮件通知 | 决定评论、状态变更、指派是否发送邮件 | 须先在「邮件」页配置发信服务 |

站点地址还决定「忘记密码」与「换邮箱」是否可用：仅 HTTPS 的站点地址可发送这两类邮件，否则入口直接产生错误。

## 模板

模板定义创建议题时需填写的内容、默认标签与关闭时执行的动作。编辑页分为四段：

- **基础信息**：模板标识（创建后不能修改）、显示名称、描述、标题前缀、默认可见性、是否启用、默认受理人、默认标签。
- **表单字段**：单行文本、多行文本、说明文字、下拉、可输入的下拉、复选框、玩家选择，可拖动排序，可设为必填。
- **完成钩子**：为「议题关闭」与「议题标记无效」两种时机配置动作，动作可为服务器命令、带颜色的提示文字，或要求管理员进行一次人工确认。
- **编辑原文**：直接修改模板配置文件，与图形编辑实时同步。

默认可见性为三选一：

| 选项 | 效果 |
| --- | --- |
| 始终公开 | 新议题对所有人可见，创建者不能修改 |
| 始终隐藏 | 新议题仅发起者与管理组可见 |
| 由创建者选择 | 创建时须二选一，未选择不能提交 |

首次初始化时，平台将若干现成模板（Bug 反馈、举报、建议、权限申请、完整示例）放入数据目录；此后这些模板与新建模板完全平级，均可修改。停用某个模板后，该模板不再出现在创建页，历史议题不受影响；删除模板同样不影响已经提交的议题。

字段的写法与钩子的配置见 [议题模板](../template/index.md)。

## 标签

每个标签包含标识（仅允许字母、数字、下划线、短横线，创建后不能修改）、显示名称、颜色与说明。标签用于列表筛选，模板亦可引用标签以实现自动标记。

## 玩家组

玩家组为模板中「玩家选择」字段的候选名单。

- 可在页面中手动添加成员（多个名字以空格或逗号分隔）、改名、移除；
- 插件亦可自动写入：在插件配置中开启玩家组上传并填写组名，玩家进入服务器时将自动加入该组；
- 删除某个组之前，先确认没有模板或完成钩子引用该组，否则相关表单将失效。

## 用户

用户列表按注册时间倒序排列。管理员可执行以下操作：

- **调整身份**：普通用户 / 管理组 / 管理员。改动后，该用户须重新登录方可生效；
- **删除用户**：此为软删除，账户的邮箱、密码、头像与游戏绑定将被清空，历史议题与评论保留，作者位置显示为已删除账户；
- 管理员不能删除自身。

## 服务器与 API Key

服务器表示议题来源，同时为插件接入的身份。每台服务器包含：

- **服务器 ID**：平台内唯一；
- **识别 ID**：用于匹配 Velocity 插件上报的服务器名，留空时等同于服务器 ID；
- 别称、地址、描述，仅用于展示与筛选。

API Key 独立管理，分为两种类型：

| 类型 | 绑定范围 | 适用 |
| --- | --- | --- |
| Paper / Folia | 须且仅能绑定一台服务器 | 单机直连 |
| Velocity | 可授权多台服务器 | 代理端后接多台后端服 |

操作注意事项：

- 新建 Key 时明文仅显示一次，当场复制到插件配置中，此后不再显示；
- 「重新生成」将使旧 Key 立即失效，所有使用该 Key 的服务器将无法连接，须同步修改插件配置；
- 修改 Key 授权的服务器列表将立即改变其可访问的范围；
- 服务器仍被 Key 绑定时不能删除，须先处理对应 Key；
- 两台服务器不能使用同一个识别 ID。

## 存储

存储页管理附件的存放位置与临时附件的额度。

- **本地目录**：文件存储在服务器磁盘上，适用于单机部署；
- **对象存储（S3 兼容）**：填写服务地址、区域、桶名、访问凭据，兼容 MinIO 等需要 path-style 的服务，可设置下载链接的有效期。

「测试连接」检测的是**已经保存**的配置，而非表单中尚未保存的内容，先保存再测试；使用本地目录时，该项将直接提示尚未配置对象存储。

切换存储后，新上传的文件使用新位置，旧文件仍按各自原位置读取；但修改本地目录或桶的配置本身将影响该位置上的所有附件，在操作前备份。

临时附件额度：

- 单个账户未使用附件的总上限，默认 50 MiB；
- 是否使未使用附件自动过期，默认开启；
- 过期天数，默认 7 天。

## 邮件

填写发信服务器的主机、端口、加密方式（465 通常使用 SSL，587 通常使用 TLS）、账号、密码、发件名称与发件邮箱，页面提供「测试连接」按钮。

开启邮件服务后，以下三项功能随之可用：网页注册要求邮箱验证码、忘记密码可发送邮件、换邮箱可发送邮件。关闭后这些功能一并停用，忘记密码的用户仅能联系管理员重置。

## Turnstile

配置 Cloudflare Turnstile 的两个 Key（站点 Key 与密钥），用于注册、登录、忘记密码与外部登录注册时的人机验证。启用时两个 Key 均须填写；密钥编辑框留空表示保持原值。

## 限流策略

| 规则 | 默认 | 说明 |
| --- | --- | --- |
| 全局请求 | 60 秒内 100 次 | 按访问 IP 统计 |
| 登录注册类 | 60 秒内 10 次 | 登录、注册、刷新登录状态、外部登录 |
| 邮件发送冷却 | 60 秒 | 注册验证码与忘记密码共用 |
| 游戏绑定保护 | 连错 5 次锁定 15 分钟 | 绑定码输入错误的保护 |

超过限制时，页面提示稍后再试。改动立即生效。

## 外部登录

配置通用的 OIDC / OAuth 2.0 登录方式：显示名称、图标、协议、服务地址、授权与用户信息端点、回调地址、客户端 ID 与密钥、权限范围、字段映射、是否启用、是否允许创建账户。

- 选择 OIDC 时须填写服务地址且权限范围包含 `openid`；选择 OAuth 2.0 时三个端点均须填写；
- 密钥为加密保存，编辑时留空表示沿用旧值；
- 页面提供「测试」以检查配置是否可用；
- 删除该登录方式前须先解除所有绑定，亦可使用「一键解绑全部」，账户与数据均保留；
- 关闭「允许创建账户」后，未使用过该方式的用户将无法通过其注册，仅可在登录后在个人资料中绑定。

## 关于

显示平台名称、构建版本、提交号与仓库地址。反馈问题时须一并附上以上各项。

## 审计记录

审计记录直接展示在议题详情页的时间线中，可见该议题的用户均能看到：状态变更、标题正文修改、可见性变化、标签增删、受理人变化、评论编辑，以及完成钩子的处理动作。连续的小改动将合并为一条。

完成钩子的执行结果同样显示在议题详情页，仅管理组可见。投递失败的动作将保留在投递记录中等待重试，目前后台尚无单独的页面入口。
