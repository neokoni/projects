# 多语言

界面文案自语言包读取，未硬编码于代码中。平台内置简体中文与英文，用户可新增语言，也可仅修改部分内置文案。

## 语言的确定顺序

界面语言按以下顺序确定，前一条不成立时采用下一条：

1. 该浏览器记录的选择（首次打开站点时记录当时生效的语言，有效期为一年）；
2. 平台默认语言（管理后台「设置 → 默认语言」；安装向导第 5 步亦会询问一次）；
3. 简体中文（内置兜底项，任一缺键均以其填充）。

邮件为例外：注册验证码、重置密码、更换邮箱、议题通知固定使用平台默认语言，与收件人的界面选择无关。

## 切换入口

| 位置 | 影响范围 |
| --- | --- |
| 个人资料 → 语言 | 仅影响当前浏览器 |
| 安装向导第 5 步「站点设置」 | 初始化时设定平台默认语言 |
| 管理后台 → 设置 → 默认语言 | 修改平台默认语言；此后新访客与全部邮件均采用该语言 |

选择记录于本地。修改平台默认语言后，此前访问过的访客可能仍沿用旧语言；如需更新，在个人资料中切换一次。

## 文件位置

| 位置 | 说明 |
| --- | --- |
| `backend/src/locales/` | 内置语言，随源码发布，升级时将被覆盖 |
| `data/locales/` | 自定义语言与覆盖文件，升级时不受影响 |
| `dist/locales/` | 构建时复制的副本，无需手工维护 |

内置语言包为 `zh-CN.json` 与 `en-US.json`。置于 `data/locales/` 的文件，若 ID 与内置相同，将覆盖对应内置文件；若 ID 不同，则视为新增语言。

修改后无需重启，刷新页面即可生效；语言文件在每次请求时从磁盘读取。

## 子页面

- [新增语言](./custom.md)：从零编写语言包，其将显示在语言选择中。
- [覆盖内置文案](./override.md)：仅修改部分措辞，其余保持原样。
