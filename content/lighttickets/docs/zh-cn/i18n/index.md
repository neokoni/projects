# 多语言

界面文案没有写死在代码里，而是从语言包读取。平台自带简体中文与英文，也可以自己加一门语言，或者只改几条内置文案。

## 语言的确定顺序

界面语言按这个顺序决定，前一条不成立才看下一条：

1. 这台浏览器上记住的选择（第一次打开站点时会把当时生效的语言记下来，一年内有效）；
2. 平台默认语言（管理后台「设置 → 默认语言」，安装向导第 5 步也问过一次）；
3. 简体中文（内置兜底，任何一处缺键都用它填）。

邮件是例外：注册验证码、重置密码、换邮箱、议题通知固定使用平台默认语言，不看收件人的界面选择。

## 切换入口

| 位置 | 影响范围 |
| --- | --- |
| 个人资料 → 语言 | 只改自己这台浏览器 |
| 安装向导第 5 步「站点设置」 | 初始化时定下平台默认语言 |
| 管理后台 → 设置 → 默认语言 | 改平台默认语言，之后的新访客与全部邮件都用它 |

选择会记在本地，所以改过平台默认语言之后，之前来过的访客可能仍停在旧语言上；在个人资料里切一次就好。

## 文件位置

| 位置 | 说明 |
| --- | --- |
| `backend/src/locales/` | 内置语言，随源码发布，升级时会被覆盖 |
| `data/locales/` | 自定义语言与覆盖文件，升级不动它 |
| `dist/locales/` | 构建时复制进去的副本，不用手工管 |

内置的两份是 `zh-CN.json` 与 `en-US.json`。放进 `data/locales/` 的文件只要 ID 与内置相同，就会盖在它上面；ID 不同则是一门新语言。

改完不需要重启，刷新页面就能看到效果——语言文件在每次请求时从磁盘读取。
